# thorbase-marketing

Next.js marketing app placeholder for STORY-01 structure.

## Local development

1. Install dependencies:
   - `npm install`
2. Copy env file:
   - `cp .env.example .env.local`
3. Start dev server:
   - `npm run dev`

## Checks

- `npm run lint`
- `npm run typecheck`
- `npm run build`
